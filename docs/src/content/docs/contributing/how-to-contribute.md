If you'd like to help out, here's how.

## Raising issues

[Raise an issue](https://github.com/Norhaven/Jolt/issues/new/choose) when you think you've found a bug, a mismatch between documentation and behavior, an idea for a new feature or library method, or a question about intended behavior that doesn't meet your expectations. There's always room to improve.

## Submitting pull requests

Please [raise an issue](https://github.com/Norhaven/Jolt/issues/new/choose) **before** submitting a PR, so we can discuss and agree on a solution that you're then welcome to help build. That way you don't spend time fixing or adding something that turns out not to be needed or intended.

## Writing tests

Testing is crucial, and it's what this project most lacks. Use these docs, the [Tests](https://github.com/Norhaven/Jolt/tree/main/Tests) folder, and the [wiki](https://github.com/Norhaven/Jolt/wiki) to find missing or incorrect test cases, then raise an issue with your findings so we can decide how to move forward.

Every example in the [library reference](../../reference/library/) that has a source and expected output is also exported as test data. See [writing documentation](../documentation/).
