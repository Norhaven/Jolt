The [Jolt Language extension for VS Code](https://marketplace.visualstudio.com/items?itemName=Norhaven.jolt) makes writing transformers easier. It provides:

- **Syntax coloring** for methods, variables, paths, and operators inside your transformer JSON
- **Code completions** for library methods and variables
- **On-hover documentation** for methods and variables
- **Real-time validation** using the Jolt library itself, so the errors you see in the editor are the same ones [`Validate()`](../../host/validation/) reports
- **A live preview** of a transformer's output for an input document, which updates as you edit either of them

Install it from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=Norhaven.jolt), from the [OpenVSX Registry](https://open-vsx.org/extension/Norhaven/jolt), or just search for **Jolt** in your Extensions view.
